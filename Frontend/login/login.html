Términos y Condiciones

Sistema de Gestión de Cuotas – Club Ciclista Maragato

1. Uso del sistema

El presente sistema tiene como objetivo facilitar la gestión de socios, cuotas, pagos y beneficios del Club Ciclista Maragato.

Al utilizar la página web, el usuario acepta cumplir con los presentes Términos y Condiciones.

2. Registro y cuenta

Para utilizar determinadas funciones del sistema, el usuario deberá contar con una cuenta proporcionada por la administración del club.

El usuario es responsable de mantener la confidencialidad de su contraseña y de no compartir sus datos de acceso con otras personas.

3. Uso correcto

El usuario se compromete a utilizar el sistema de manera responsable y únicamente para las funciones disponibles.

No está permitido:

  • Intentar acceder a cuentas o información de otros usuarios.
  • Modificar o eliminar información sin autorización.
  • Utilizar el sistema con fines maliciosos.
  • Intentar afectar el funcionamiento de la página.

4. Información de los socios

La información ingresada en el sistema deberá ser correcta y actualizada.

Los datos serán utilizados para las funciones relacionadas con la gestión de socios, cuotas, pagos y beneficios del club.

5. Pagos y cuotas

El sistema permite consultar el estado de las cuotas y los pagos registrados. Los pagos estarán sujetos a la correcta confirmación de la operación.

6. Disponibilidad del sistema

El sistema puede presentar interrupciones debido a tareas de mantenimiento, actualizaciones o problemas técnicos.

El equipo encargado procurará mantener el servicio disponible y funcionando correctamente.

7. Modificaciones

Los presentes Términos y Condiciones pueden ser modificados cuando sea necesario para mejorar o actualizar el funcionamiento del sistema.

8. Aceptación

Al marcar la casilla de aceptación, el usuario declara haber leído y aceptado estos Términos y Condiciones.

Última actualización: 2026.
